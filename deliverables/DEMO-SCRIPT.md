# 3–5 分钟演示脚本草稿（BlockCraft AI）

- 适用基线：**origin/main @ 4a95cae**（2026-10-19 浏览器 QA 15/15 PASS）
- 演示机器要求：见《演示前检查清单》（DEMO-CHECKLIST.md）；本脚本默认**未配置任何密钥/授权**，生成主线走**可信番茄钟（离线演示）**，全程零付费调用
- 铁律：只演示实际存在的能力；不把离线 Fixture 说成"实时自然语言 AI 生成"；Mochi 对话修改如实说明"尚未启用"；v1 生成入口需服务端授权（未授权会诚实报错，不是 BUG）

## 台词与操作（逐段）

### 0. 开场（`/ai-create` 落地页）

> "大家好，这是 BlockCraft AI。你用一句话描述想要的软件，系统把它变成一块块'功能积木'——表单、名单、统计、计时——搭成一个马上能用的应用。右边是我们的吉祥物 Mochi。"

### 1. 离线主线（可信番茄钟）

操作："创建方式"下拉选 **可信番茄钟（离线演示）** → 提示出现"…加载固定的 25 分钟番茄钟配置，由可信内置组件计时；此演示不会根据自然语言生成内容。" → 点 **加载离线番茄钟** → 应用「考试专注番茄钟」出现。

> "页面明确标注了当前来源：离线固定 Fixture，非真实 DeepSeek 调用——演示现场无网络、无密钥、零费用，也能完整展示积木到应用的全链路。如果部署端配置了授权与密钥，'AI 应用（原有 v1）'模式就是真实的大模型生成，页面提示写得很清楚。"

### 2. B 模式（编辑积木）

操作：点 **B 模式 · 编辑积木**（aria-label），点击"01 数学专注 可信倒计时"积木卡。

> "这是应用的'内部视角'：每块积木对应一个功能单元。右侧 Mochi 面板提供上下文与建议入口。"

### 3. C 模式（运行应用）

1. 在番茄钟应用点 **C 模式 · 运行应用**：计时显示 25:00，点开始 → "计时中"（可暂停/重置）。
2. 打开 `/app-renderer`（通用应用预览）：社团报名示例——表单提交（"已保存"）、名单"新增记录"行数 +1、点"删除"行数 -1（main 已改为单步删除）。

> "运行视图里表单、名单读写同一份数据；番茄钟由可信内置组件计时，不依赖任何外部服务。"

### 4. 诚实边界（一定讲，主动讲）

1. Mochi 面板："**AI 修改能力尚未启用：DeepSeek 修改计划 API 尚未接入。可继续手动编辑积木与运行应用。**"
   > "对话式修改在路线图上，当前版本如实禁用，不做假的。"
2. 应用页"当前应用来源"标注："**离线固定 Fixture，非真实 DeepSeek 调用**"。
3. 页面提示："**数据仅保留在当前页面，刷新后清空**"（刷新演示即回到落地页）。
   > "无账号、无持久化，这是演示版有意的边界。"

### 5.（可选）v1 生成入口与授权说明

操作：创建方式切回 **AI 应用（原有 v1）**，输入创意，点"生成应用"。
- 部署端已注入授权 → 真实生成流程（付费可能发生，需提前演练）。
- 未授权 → alert "生成失败（HTTP 401）…已保留"（授权门）或 "生成失败（HTTP 502）…已保留"（详见 QA 报告 F1：CRLF 检出下 v1 投影自检 fail-closed，LF/CI 环境正常；修复归 server owner）。

> "无论哪种结果，页面都诚实报错且**保留当前应用与数据**——这是我们专门用浏览器测试验证过的行为。"

### 6. 备用（时间富余）

- Workshop 内 **导出 React 项目**：把当前应用导出为可构建的 ZIP（main 已支持；`tools/project-zip-export` 有独立测试）。
- `/app-renderer` 切换"社团迎新报名 / 阅读记录"两套示例，说明 C 模式渲染是通用的。

## 常见评委问题 · 应对口径

| 问 | 答 |
| --- | --- |
| "现在是真 AI 吗？" | 两条线如实分开："可信番茄钟"=离线固定 Fixture（页面标注来源）；"AI 应用（原有 v1）"=需服务端授权+密钥的真实 DeepSeek 生成。Mochi 对话修改当前未启用（UI 明确禁用）。 |
| "为什么不把离线演示包装成实时 AI？" | 项目规范要求演示描述与实际能力一致；来源标注直接写在页面上。 |
| "数据能保存吗？" | 页面内存，刷新即清空；但可"导出 React 项目"把成果带走。 |
| "AI 会执行代码吗？" | 不会。模型输出必须通过 `assertAppSpec` 完整校验，只作为数据渲染；番茄钟等可信组件来自内置代码，不来自模型。 |
| "多个人能一起用吗？" | 不能。单机演示版；后端限流为单进程内存级，且生成接口有授权门与限流。 |
