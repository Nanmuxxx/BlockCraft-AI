# 项目 JSON 导出与导入

工坊现在支持下载和恢复 `blockcraft-project.json`。文件是本地项目备份，不会写入服务器，也不会修改已部署的 ModelScope 空间。

文件格式为 `blockcraft-project`，当前版本为 `1`，包含：

- 完整的 `CustomProject` 快照，包括 AppSpec、业务记录、积木位置、渲染顺序、计时状态、自定义积木实例、props 和 state；
- 项目引用的每个自定义积木的精确 `definitionId`、`versionDigest` 和校验过的惰性源码制品。

导出会先读取当前唯一项目 owner 并重新校验精确制品版本。导入会先完整解析、限制 JSON 大小、校验项目结构、组件 schema、能力引用和内容摘要，再创建新的 Runtime。任何失败都会保留当前 Runtime、记录和编辑状态；导入不会使用 `latest` 或网络上的替代版本。

导入替换当前项目，以及重新生成替换当前项目时，先把旧项目完整保存到浏览器 IndexedDB；只有写入事务成功且项目没有在备份期间变化，才发布新项目。备份追加保存，不覆盖或自动删除旧条目。浏览器不允许保存或存储空间不足时，中止替换，保留当前项目。工坊可选择历史备份并下载 JSON，首页和工坊均可直接恢复所选备份。无需服务器或新增依赖。

使用步骤：

1. 在工坊点击“下载项目 JSON”，确认浏览器已保存文件。
2. 重新进入 BlockCraft AI，在首页选择“导入项目 JSON”，打开文件即可继续预览、填写数据和编辑积木。
3. 在已有项目中导入其他 JSON 时，旧项目自动保留本地备份；首页或工坊的“恢复所选备份”可以找回替换前的项目。

文件上限为 4 MB，并沿用项目协议的深度、节点、字符串和结构限制。选中文件后先检查大小，再读取和解析。自定义积木以原有惰性源码制品保存，重新运行仍需兼容的编译和沙箱服务，JSON 不是独立运行的网页。撤销历史、待确认的 AI 计划、访问码与服务端凭据不属于项目文件；恢复后从新编辑会话开始。

当前不提供云端分享链接、权限管理或跨部署同步。页面刷新会清空当前内存会话，请在刷新前下载 JSON；本地历史备份只记录被替换前的快照，不是实时自动保存。IndexedDB 备份限同一浏览器和站点，清除站点数据、隐私模式结束、存储回收等可能导致备份消失，因此长期保存和跨设备迁移应以下载的 JSON 为准。

验收：`npm run build`、`npm test`、`npm run test:project-json`、`npm run test:project-json:browser`。浏览器验收使用 Playwright（已有本地安装可通过 `NODE_PATH` 复用，Chromium 可通过 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 指定），所有生成接口使用离线 fixture，不访问已部署空间或付费 AI。
