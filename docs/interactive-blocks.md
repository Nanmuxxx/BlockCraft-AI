# 互动积木阶段说明

本阶段扩展了一句话生成和运行时互动协议，新增三类内置积木：

- `filter`：对同一实体的指定字段进行搜索和精确筛选；
- `chart`：按一个字段分组显示柱状图或折线图，支持记录数、数值合计和数值均值；
- `details`：从显式绑定的列表选择一条记录后只读展示详情。

互动关系必须写在积木配置中。`filter` 可以显式影响列表、指标和图表，`chart` 可以显式影响列表和指标，`details` 只能引用同一实体的列表。校验会拒绝跨实体关系、自引用、循环、脚本字段和未声明目标。

搜索、筛选、图表选择和详情选择属于会话状态，不改变业务记录、项目结构、版本号或结构撤销历史。业务数据变化后会重新计算可见结果，结构变化会清空互动会话状态。

项目 ZIP 会保留新积木的配置、资源、记录和顺序；独立 React 源码 ZIP 目前明确拒绝包含这些积木的项目，避免生成不完整的运行时。Mochi 的受控修改阶段暂不接入 `filter`、`chart`、`details` 的修改，用户可在属性面板配置它们。

当前仍未覆盖的积木类型包括动画、跨实体查询、公式、时间区间查询、外部服务和自动流程。图库继续支持本地资源预览，指标继续支持显式筛选联动。
