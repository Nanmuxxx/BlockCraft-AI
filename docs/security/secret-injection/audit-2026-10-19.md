## 新发现的阻塞

Gateway #63 `c1c7df0c68e9c7ecc337ffd296ed5a3042615e4b` 在临时合成账本上可复现幂等重复：

1. 对相同ledger lease/directory/bindingKey打开sidecar句柄a和b。
2. a为一组principal/key/payload创建claim并reserve，模拟成功usage并结算。
3. b以相同principal/key/payload再次reserve成功。
4. 结果ledger有2条reservation，sidecar只有1条claim。
