演示降级步骤：

1. 赛前在本机准备此 SHA 的 production dist 与依赖，启动仅本机静态预览；打开 `/ai-create?gallery=1`，逐一预热六案例，默认用桌面尺寸。明确介绍为“离线 AppSpec 示例，非实时 AI 生成”。
2. 网络/生成错误时留在当前应用，已有记录仍可用；若请求挂起，点“取消生成”，然后“查看案例”→选择示例→确认加载。不要为了恢复展示去启用付费接口或改鉴权/预算。
3. 输入报错时补齐必填字段后单击提交。快速重复点击已有保护，但不承诺对重新填写的相同业务内容做去重。
4. 切错案例时在确认框点“取消”；确需清场时再次选择同案例并“确认加载”，恢复固定初始数据。此操作会丢弃当前内存编辑。
5. 页面失去响应时，在接受临时数据丢失后刷新，重新加载同案例。恢复的是初始 fixture，**不恢复此前输入的数据**。本地服务不可用时先由演示操作员恢复原本机静态预览进程，再重新进入 Gallery；此进程重启步骤为预案，未注入进程崩溃验证。
6. 移动表格难读时转到桌面投屏；现场设备或本机服务无法恢复时，展示本次截图/预先录制材料并明确说明是预录证据，暂停实时演示。
