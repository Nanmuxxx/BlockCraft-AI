# Controlled Phase 2 DeepSeek gateway

Only the explicitly authorized operator may run `node tools/real-deepseek/evaluate.mjs --live`. The ordinary server has no generation identity adapter and denies legacy v1 and v2 before Provider access. Origin/CORS never grant identity. The local evaluator generates a random 256-bit bearer token, keeps it in server memory, and injects it only in its server-side loopback Vite proxy. No token or API key enters the webpage bundle, URL, report or Git. No proxy listener is exposed beyond IPv4 loopback. Mochi remains disabled and CustomBlock native egress is blocked. Trusted injected transports are server-code configuration, not a browser-controlled permission.

The evaluator reads the existing primary repository `server/.env` in process, never prints its content, and uses only `DEEPSEEK_API_KEY`. It fixes model `deepseek-flash` and the official HTTPS completion endpoint. It does not modify production or Docker configuration. Never deploy this local evaluator/proxy as a public service.

Pricing verified 2026-10-19: https://api-docs.deepseek.com/zh-cn/quick_start/pricing/ . Peak cache-miss input ¥2 / million tokens, output ¥8 / million. Cache/discount savings are ignored. Thinking disabled, JSON mode, max_tokens <=8192, no tools, retries=0, redirects rejected, concurrency=1, timeout <=30s. The pricing snapshot expires before the next day; later use requires explicit re-verification.

One canonical private ledger under the common workspace parent is shared across worktrees. Atomic fsync-before-network reservations and an exclusive process lock protect it. Crash leases are never automatically removed; an incomplete/uncertain call halts the ledger. Missing, corrupt or over-bound usage halts automatic calls. All reservations remain charged to the internal allowance even after trustworthy cheaper usage. Audit retains only request hash, time, model pricing, reservation, usage and estimated cost; no request text or credentials.

User authorization is ¥10 total with ¥8 auto-stop. This implementation is more conservative: at most ¥1 reserved and six attempts, and never reserves across ¥8/¥10. Input reservation uses UTF-8 bytes plus 8192 framing tokens; this is a conservative software bound, not a tokenizer proof or supplier-side hard spending limit. Usage is checked against the reservation. Software cannot control supplier price changes, provider accounting defects, other account users or arbitrary code bypassing this trusted runner. No claim of a supplier hard limit is made. Unknown results stop rather than refund/retry; operator must reconcile the provider account before any future authorization.

Offline tests never read `.env`, never call the native network transport and use separate temporary ledgers. Persisted real responses are allowlisted and scanned; only AppSpec JSON is interpreted by the existing strict validator and trusted renderer. Generated TSX is never executed.

## Model/configuration contract (integration owner handoff)

Paid composition defaults to `PRICING.model` (`deepseek-flash` in this dated price snapshot) only when the injected transport is the exact branded `createPaidTransport` instance. This applies to `createAppServer` and separately authorized Mochi/CustomBlock Providers; an explicit `model: PRICING.model` remains supported. Supply the exact same `fetchImpl` returned by `createPaidTransport` and canonical shared ledger; do not construct a ledger per consumer. The entry also requires `generationAccess` (default deny); v2 additionally requires its existing admission gate. Provider identity/configuration does not replace endpoint authentication. CustomBlock additionally requires its existing explicit `allowPaid` gate. This contract does not authorize enabling those features or executing generated TSX.

Historic defaults (`deepseek-v4-flash`) are preserved for ordinary offline/native transports. They deliberately do NOT imply gateway compatibility or paid authorization. Only the branded paid transport selects the priced default; arbitrary injected wrappers do not. Explicit constructor models and existing entry/Mochi DEEPSEEK_MODEL configuration take priority and are never silently corrected. CustomBlock retains its existing no-env-read contract. The gateway accepts ONLY the exact price-snapshot model, rejects old aliases before reservation/network and never silently rewrites them; selecting an arbitrary DEEPSEEK_MODEL cannot change its price approval. CustomBlock's construction allowlist includes exact `deepseek-flash`, while older names remain available only to explicitly trusted offline adapters. The snapshot expires at its recorded time; this patch does not extend it, raise any cap, reset the canonical ledger or approve more real calls.

`requireControlledEgress` is a guard against accidental direct use of the captured native fetch. It is NOT a sandbox or proof that every injected function is budget-controlled: arbitrary injected functions (including wrappers around native fetch) are trusted server code and can bypass it. The audited path requires the exact branded `createPaidTransport` instance; `isPaidTransport` is provenance, not endpoint authorization. Browser requests cannot inject a transport; anyone able to modify server code can also remove guards. Do not claim protection from malicious server code. Public/multi-user production authentication and Docker packaging remain unimplemented/BLOCKED; this document is an integration contract, not a deployment approval.

Offline evidence: `tests/paid-gateway/model-contract.test.mjs` rejects both old aliases through all three consumers with zero reservations/network, then composes all three with the exact priced model and one shared six-call audit ceiling. Synthetic CustomBlock output remains inert text. The monetary ceiling, cancellation and unknown-usage halt remain covered by the eleven independent security tests. No live calls are used.

## Audit callback deadline and metadata boundary

The connection/body timeout and caller cancellation also bound the asynchronous `onResponse` wait. Callbacks receive `{ id, requestHash, signal }`; cancellation/timeout rejects the transport and ignores any late callback result. The concurrency flag and listeners are released in finally. Callback code is trusted server code: it must honor the signal for its own I/O/side effects, and a synchronous event-loop-blocking callback cannot be preempted by a JavaScript timer. No callback-side-effect rollback is promised. Trustworthy upstream usage is already durably settled before audit; a failed/cancelled callback retains the full reservation and settled usage, with no refund/retry. Unknown upstream usage continues to halt automatic calls.

The emitted response and callback copy use only `PRICING.model` as the configured request model, never upstream `envelope.model`. This prevents untrusted model metadata (including a key echo) from entering saved audit samples or HTTP responses. It does not attest the provider's internal model identity. Assistant content remains key-scanned, usage is validated and normalized, and all other upstream fields are excluded. Previously recorded live evidence is immutable; the follow-up uses synthetic sentinels only, with no evidence of an actual key leak during those two live calls.
